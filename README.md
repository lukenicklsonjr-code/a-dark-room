# A Dark Room (modified)

A modified version of A Dark Room, a minimalist text adventure by Michael Townsend (doublespeak games)
and contributors, released under the Mozilla Public License 2.0 (see `LICENSE.md`).

Original: https://github.com/doublespeakgames/adarkroom (commit 1fada4620b6c66bd07bf15a3f1eb8223df8bc1d7).

Changes: English only (translations removed); removed analytics, the jQuery CDN (local copy used), app-store,
share, GitHub and cross-promotion links, and the redirect that sent phones and tablets to an app page.

Modified on 2026-11-17. The page loads `/mute.js`, a small separate script provided by the host
that lets the surrounding page switch the game's sound on and off.
